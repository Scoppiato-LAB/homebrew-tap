# Scoppiato LAB Homebrew Tap

Official Homebrew Tap for Scoppiato LAB utilities and open-source command-line tools.

## Installation

Add this tap to Homebrew:

```bash
brew tap Scoppiato-LAB/tap
```

Install **sltop**:

```bash
brew install Scoppiato-LAB/tap/sltop
```

Or directly in one line:

```bash
brew install Scoppiato-LAB/tap/sltop
```
